# dsh-index-fund-guide

把《指数基金投资指南》（银行螺丝钉）的**估值—定投—卖出体系**做成一个能算、能核、能落地的工具箱，以 DSH 插件形态分发。

它不预测涨跌，也不替你做决定：只做三件事——**把书里的方法算清楚、把数据的来路摊开、把结论成立的前提写明。**

## 一、功能

| 能力 | 说明 |
|---|---|
| 买卖信号 | 按「四类指数 → 四种方法」自动分派，给出信号、依据与所用阈值口径 |
| 阈值校准 | 按当期无风险利率与债基收益重算买卖线，book / cal / cal-rp 三套口径并存 |
| 自算 PE/PB | 取成分股行情与财报自己除，输出五种口径并逐只与公开值对账 |
| 组合分配 | 按低估深度分配预算，带单只与同质组上限；全市场都不低估时指向债券基金 |
| 定期不定额 | 按「越低估投越多」放大或缩小本月投入金额 |
| 定投年化 | IRR / XIRR，按每笔资金的实际在场时间加权 |
| 记账与真实收益 | 持仓成本、浮动盈亏、已实现盈亏、累计分红、真实年化 |
| 定投计划 | 生成可打印填写的四段式计划表 |
| 回测 | CSV 驱动，对比「估值定投 vs 无脑定投」 |
| 每日跟踪 | 关注清单 → 快照 → 动作与建议金额 → 日报 |
| 保真测试 | 71 项离线断言，把书中可复现的数字钉成回归测试 |

### 方法分派

同一个 PE，用对方法和用错方法会得出相反结论，所以先分类、再谈买卖：

| 类型 | 适用品种 | 方法 |
|---|---|---|
| `value` / 价值 | 上证50、沪深300、红利、恒生、H股 | 盈利收益率法 |
| `grow` / 成长 | 创业板、中证500、纳指100 | 博格公式 + PE 历史分位 |
| `cycle` / 周期 | 证券、银行、能源、地产 | 博格变种 + PB 历史分位 |
| `distress` / 困境 | 产能过剩行业、长期衰退市场 | 放弃 |

三条纪律：低估不等于会涨；低利率下盈利收益率法几乎不触发卖出，必须叠加历史分位；方法选错，结论反转。

## 二、下载与安装

```bash
pnpm add https://github.com/LipingAn04/dsh-index-fund-guide.git
```

再把 `dsh-index-fund-guide` 加入 profile 的 `package.json` → `dsh.profile.bundles`，重启 DSH 后 `skill({ name: "index-fund-guide" })` 即可加载。

- 仓库地址：<https://github.com/LipingAn04/dsh-index-fund-guide>
- 安装细节（三种方式、已知的安装坑、目录结构）：[INSTALL.md](INSTALL.md)

- 更新日志：[CHANGELOG.md](CHANGELOG.md)
- 脚本可脱离 DSH 单独使用：`skills/index-fund-guide/scripts/` 下 4 个 Python 文件，零第三方依赖
