# 指数基金投资指南 · 估值定投实战手册

本技能把《指数基金投资指南》(银行螺丝钉) 的完整方法体系压缩成一套**可执行决策规则**：先判断品种属于哪一类，再选对应的估值方法，算出买/持/卖信号，最后落到定投计划表上。

一句话内核：**只在低估值时定投，正常估值时持有，高估时卖出，循环往复。**

## 两个时间戳，必须分清

| 内容 | 时间 | 状态 |
|---|---|---|
| 方法论（分类、公式、定投四步、配置法则） | 长期 | **有效，直接用** |
| 基金名单、指数回测、案例数字 | 2017-05 | 标本，用于理解，**不可当现状引用** |
| 买卖阈值（10% / 6.4%） | 2017-05 → **2026-10 已校准** | 阈值随利率变，见 `references/07-calibration.md` |
| 当前估值快照（各指数 PE / 分位 / 股息率） | 2026-10-16 | 半年内可参考，**决策前必须重新取数** |

回答时必须说清：这句话来自书里的哪一年，还是来自 2026 年的校准。

## 30 秒决策树

```
用户问"这只基金能买吗"
   │
   ├─ 1. 它是什么品种？(宽基/行业/子行业) ──→ 见 references/02-catalog.md
   │
   ├─ 2. 查它当前的 PE / PB / 股息率 / 历史分位
   │
   ├─ 3. 按"盈利是否稳定"分四类，选方法：
   │      盈利稳定（价值指数）────→ 盈利收益率法（阈值法，最简单）
   │      高速增长（成长指数）────→ 博格公式 + PE 历史分位
   │      不稳定/周期但不长期亏损─→ 博格公式变种 + PB 历史分位
   │      长期亏损（困境指数）────→ 直接放弃，不适用任何估值法
   │
   ├─ 4. 选阈值口径（书中/校准A/校准B，见下节）── 这一步会改变结论
   │
   └─ 5. 出信号：分批买 / 坚定持有 / 分批卖
```

**第 4 步是关键**：同一批数据，换一套阈值，七个指数里六个的结论会变。所以任何信号都要连带说明口径，不能只说"低估"。

## 方法分派表（这是最容易错的一步）

**同一个 PE 数字，用对方法和用错方法会得到相反结论。** 必须先分类，再算。

| 品种类型 | 代表 | 方法 | `--method` | 判据 |
|---|---|---|---|---|
| 盈利稳定（价值指数） | 上证50、沪深300、红利、恒生、H股 | 盈利收益率法 | `yield` | 1/PE 对照 10% / 6.4%(或校准线) |
| 高速增长（成长指数） | 创业板、中证500、纳斯达克100 | 博格公式 + PE 分位 | `bog` | PE 历史分位 <30% 可投 |
| 不稳定/周期但无长期亏损 | 证券、银行、能源、地产、标普500 危机期 | 博格变种 + PB 分位 | `pb` | PB 历史分位 <30% 可投 |
| 长期亏损（困境指数） | 产能过剩行业、经济长期衰退国股市 | 放弃 | `skip` | 任何估值都不买 |

```text
# 分派正确: 创业板 PE 31.9 看似该卖, 但它是成长指数, 应按分位判断
<python> scripts/valuation.py signal --method bog --pe 31.90 --pe-type ttm --percentile 18.2
#   -> 历史较低区域(可投); 同时交叉验证会提示"盈利收益率法本就不适用"

# 分派错误: 同一只指数用盈利收益率法
<python> scripts/valuation.py signal --pe 31.90 --pe-type ttm
#   -> 分批卖出 + 警告"盈利收益率法本就不适用"

# 周期股: PE 被盈利崩塌拉到 264 倍时, 必须看 PB
<python> scripts/valuation.py signal --method pb --pb 1.1 --pb-type lyr --percentile 12.0
```

**PE 分位与 PB 分位的 30% / 70% 分界线是本工具自定的**（书里只写"历史较低/较高区域"，没给数字），脚本每次都会打印这条声明。用它得出的结论可信度低于盈利收益率法，要向用户说明。

## 核心阈值表

### 书中 2017 口径（保守基准，脚本默认）

| 判断依据 | 买入 | 持有不动 | 卖出 |
|---|---|---|---|
| **盈利收益率** = 1/PE | > 10%（分批投） | 6.4% ~ 10% | < 6.4%（分 10 份，每月卖 1 份） |
| **PE 历史分位** | 处于历史较低区域 | 正常估值区 | 进入历史高估区（如 PE 40+ 的 2007 年） |
| **PB 历史分位** | 处于历史较低区域 | 正常区 | 进入历史高估区 |
| **股息率** | 处于历史高位时买入 | — | 股息率被压得极低时 |

阈值的来历（不是拍脑袋）：**6.4%** = 当时国内债券基金的长期平均收益，低于它就不如买债基；**10%** = 格雷厄姆"盈利收益率要大于 10% 且大幅高于无风险利率"，当时 10 年期国债约 3.5%，两倍是 7%，取整合并为 10%。

**港股品种打折**：恒生指数、恒生中国企业指数（H 股指数）的盈利收益率要**打 9 折**再用（港股通分红税 + 换汇成本）。

> 9 折是书里的粗口径（对所有盈利一律打折）。更准的做法是**只在分红上扣税**：`盈利收益率 − 股息率 × 税率`。恒生 2026-10 实测：粗口径 9.41%×0.9 = 8.41%，精确口径 9.35% − 3.38%×0.2 = **8.67%**——粗口径把港股系统性低估了约 0.26pct。已知股息率时优先用 `--hk-exact`。

### 2026-10 校准口径（当期环境）

无风险利率 3.5% → **1.648%**；债基跨周期平均收益 6.4% → **3.0%**（前瞻可持续，不是 22 年均值 4.43%）。

| 口径 | 买入线 | 持有区 | 卖出线 | 特点 |
|---|---|---|---|---|
| `book` 书中 2017 | > 10%（PE<10） | PE 10~15.6 | < 6.4%（PE>15.6） | 最保守，卖出最容易触发 |
| `cal` 校准A 教材直译 | > 10%（PE<10） | **PE 10~33.3** | < 3.0%（PE>33.3） | 买入线不动，**卖出几乎永不触发** |
| `cal-rp` 校准B 风险溢价平移 | > 6.6%（PE<15.2） | PE 15.2~33.3 | < 3.0%（PE>33.3） | 承认估值中枢上移，更激进 |

**两条线为什么不同步降**：买入线锚定格雷厄姆的绝对安全边际（10% 硬门槛，利率再低也不松）；卖出线锚定"持有股票已不如持债"（随债基收益一起跑）。利率越低，两者距离越大。

**校准的核心后果**：低利率下卖出条件失效（PE>33 在 A 股历史上只对应极少数泡沫）。所以校准之后，**卖出判断必须改由 PE/PB 历史分位承担**，不能只看盈利收益率。

### 当期实测（2026-10-16，2026-10 口径）

| 指数 | PE | 盈利收益率 | PE 分位 | 书中 | 校准A | 校准B | 分位 |
|---|---|---|---|---|---|---|---|
| 中证红利 | 9.01 | 11.10% | 86.1% | 买 | 买 | 买 | 高估 |
| H股指数 | 9.35 | 9.63%（9折后） | 64.5% | 持有 | 持有 | 买 | 中位 |
| 上证50 | 10.78 | 9.28% | 58.8% | 持有 | 持有 | 买 | 中位 |
| 恒生指数 | 10.70 | 8.41%（9折后） | 53.6% | 持有 | 持有 | 买 | 中位 |

## 两种主方法（速记）

**① 盈利收益率法（格雷厄姆）** — 只适用于盈利稳定的品种
```
盈利收益率 = 1 / 市盈率      （PE 8 → 12.5%）
买入: >10% 分批投 ｜ 6.4%~10% 持有 ｜ <6.4% 分批卖   （2017 口径）
```
回测（2004–2015 每月等额定投）：上证 50 年复合 **29.27%**（无脑定投仅 12.3%），红利指数 **29.9%**（无脑 13.07%）。注意：这是 2004–2015 中国经济高增长期的结果，作者说未来大概率 15%~20%。

**② 博格公式（约翰·博格）** — 适用于成长/周期品种
```
年复合收益率 = 初始股息率 + 每年市盈率变化率 + 每年盈利增长率
```
沪深 300 十年实测：1.86% + (−4%) + 14.4% ≈ **12.26%**（扣费后约 11.7%）。

**变种（PB 法）** — 盈利不稳定但净资产有保障时用
```
年复合收益率 = 每年市净率变化率 + 每年净资产变化率
```
证券行业 2004–2005 年就靠 PB 才看出便宜（PE 被盈利崩塌被动拉到 264 倍，看着贵其实便宜）。

## 四步工作流

1. **定品种** → 查 `references/02-catalog.md` 确认它属于宽基还是行业、盈利是否稳定、该用哪套方法。
2. **取原料、自己算** → 不要抄现成的 PE/PB 结论，用 `scripts/rawdata.py` 把**总市值、净利润、净资产、收盘价**取回来自己除：
   ```text
   # 取原料（成分股名单 + 行情 + 财报），缓存到 ./_ifg_cache
   <python> scripts/rawdata.py fetch --index 000300

   # 自己算 PE/PB，逐只与公开数据对账，导出明细 CSV，并与公开值比一次
   <python> scripts/rawdata.py calc --index 000300 --verify --csv 000300.csv --published-pe 12.9964
   ```
   `calc` 会打印 `Σ总市值 / Σ净利润 = PE`、`Σ总市值 / Σ净资产 = PB`，并给出**逐只误差中位数**（实测 300 只里 97.5% 的个股 PE 误差 ≤1%）与**指数层偏差**（5 个指数 PE 偏差均 <1.5%）。偏差来源只有三处：加权方式（总市值 vs 调整市值）、PE 口径（静态/TTM/动态）、净资产口径（归母 vs 全部）。详见 `references/08-raw-data.md`。
   算不了的情形（港股、接口不可用、用户没空跑）：让用户提供当期 PE 并注明**数值、来源、口径、日期**四要素，**任何情况下不许编造数字**；不知道去哪查就报 `scripts/valuation.py sources`。
3. **定口径 + 出信号** → 先决定用 book / cal / cal-rp，再算：
   ```text
   # 用当期利率重新推导买卖线，并看两种变体的取舍
   <python> scripts/valuation.py calibrate --riskfree 1.65 --bond-avg 3.0 --as-of 2026-10

   # 盈利收益率法：给 PE 出买/持/卖信号（港股加 --discount 0.9，一定选口径）
   <python> scripts/valuation.py signal --pe 12.33 --pe-type ttm --pe-alt 13.39 --pe-alt-type lyr --preset cal

   # 已持有时，直接问"该不该卖"：分位是校准后的主判据（>70% 分批卖）
   <python> scripts/valuation.py position --percentile 86.1
   # 没有现成分位、但手里有历史 PE 序列（CSV: date,pe）时，用真实分位而不是按 PE 区间线性插值
   <python> scripts/valuation.py position --series 沪深300历史PE.csv --value 13.0

   # 博格公式：拆解三个来源（书中沪深300 十年实例，PE 从 19.71 降到 13.17）
   <python> scripts/valuation.py bog --dividend 1.86 --pe-now 19.71 --pe-future 13.17 --years 10 --earnings-growth 14.4

   # 定期不定额：按当前估值放大/缩小本月金额（--mode yield|pe|pb）
   <python> scripts/valuation.py amount --base 1000 --mode pe --first 10 --now 7.5 --n 1

   # 月度预算分给多个候选品种；单只上限/同质组上限；一个都不低估时自动给"钱去哪"
   <python> scripts/valuation.py portfolio --budget 2000 --candidates "000922:9.01:1:yield,510300:13.0:1:yield,399006:31.9:1:bog:18.2" --max-single 0.5 --group "510050+510900" --max-group 0.5

   # 校验这套规则的历史行为（序列 CSV 需含 date + 估值列 + 点位列）
   <python> scripts/valuation.py backtest --series 沪深300历史.csv --amount 1000

   # 不知道去哪取数时，打印取数清单与口径陷阱
   <python> scripts/valuation.py sources
   ```
4. **落计划** → 用 `references/04-plan.md` 的四段式定投计划表 + `scripts/dingtou.py` 算收益率、记流水：
   ```text
   # 定投年化收益率（推荐 --invest 写法，避免负号转义问题）
   <python> scripts/dingtou.py irr --invest 1000,1000,1000,1000,1000,1000,1000,1000 --final 9500

   # 日期不固定时用 XIRR
   <python> scripts/dingtou.py xirr --flows 2026-01-05:-1000,2026-07-01:2300

   # 生成可直接打印填写的定投计划表
   <python> scripts/dingtou.py plan --income 10000 --expense 6000 --age 35 --out 我的定投计划.md

   # 记一笔定投，然后看汇总（书里表 6.1 的电子版）
   <python> scripts/dingtou.py record --file 定投记录.csv --date 2026-10-20 --action 买 --code 000922 --name 中证红利 --amount 1000 --shares 95.2 --fee 0.5 --valuation 9.01 --valuation-type PE
   # 分红到账也记一笔（不记分红，高股息品种的年化会被系统性低估约 3~4pct）
   <python> scripts/dingtou.py record --file 定投记录.csv --date 2026-11-20 --action 分红 --code 000922 --name 中证红利 --amount 41.4
   <python> scripts/dingtou.py report --file 定投记录.csv --nav 000922:1.6

   # 改完脚本/文档后，一条命令验证书中可复现的数字没跑偏
   <python> scripts/selftest.py
   ```
   `record` 写 CSV 后，`report` 直接给出成本、份额、**已实现盈亏 + 浮动盈亏 + 累计分红 + 累计费用**与**真实年化（XIRR）**——不用再手工把表格转成 IRR 参数。`--action` 取 `买 / 卖 / 分红`，卖出按**持仓均价**结转成本（不把已实现盈亏混进成本），分红按现金入账计入 XIRR。两个脚本都支持 `--json` 输出。所有子命令的完整参数见 `-h`。

## 卖出：巴菲特三条件

1. **基本面恶化** — 对指数基金≈国家经济长期衰退，国内基本用不上。
2. **过于昂贵** — 估值进入历史高估区。⚠️ 2017 口径看"盈利收益率 < 6.4%"，但**校准后这条在 2026 环境里几乎不触发**，实际应看 PE/PB 历史分位（>70% 分位分批卖）。
3. **有更好的品种** — 同质品种间估值倒挂时换仓（如某些时点上证 50 与 H 股指数谁更便宜会互换）。

没触发就不卖。**大多数时间要做的事就是坚定持有，享受复利。**

### 卖出的三层判据（按优先级）

1. **PE/PB 历史分位 > 70%** ← 校准后唯一稳定可用的判据（2026 年卖出线 PE>33 几乎不触发）
2. **盈利收益率 < 卖出线**（book 口径 6.4% / cal 口径 3.0%）← 理论正统，但低利率下极少触发
3. **有更便宜的同类品种**（同质组内估值倒挂时换仓，如恒生 vs H股）

三者冲突时按 1 处理，并明确告诉用户"第 2 条在你的利率环境里已经失效"，而不是硬套书里的数字。

## 脚本运行环境

四个脚本（valuation / dingtou / rawdata / selftest）只用 Python 3 标准库（argparse/json/csv/datetime/urllib），无第三方依赖，Python 3.6+ 均可运行。只有 `rawdata.py` 需要联网（东财 + 腾讯行情），其余脚本离线可用。

- `<python>` 替换为环境里的解释器：Windows 常用 `python`、`py` 或本机 runtime 的全路径；不确定时先调 `load_workspace_dependencies` 拿路径
- 路径含中文/空格时加引号
- **Windows 控制台是 GBK**：脚本已把 stdout 改成 `errors="replace"`，中文在控制台可能显示为乱码，但数值正确；需要原样中文时设 `PYTHONIOENCODING=utf-8` 或重定向到文件再读
- **PowerShell 特别注意**：以负号开头的参数值会被当成选项，所以现金流优先用 `--invest ... --final ...`，或用等号形式 `--cashflow=-1000,-1000,6000`

## 已知失效点与数据预案

| 风险 | 表现 | 应对 |
|---|---|---|
| 蛋卷 `index_eva` 接口未公开文档化 | 改结构、加校验、限流、或停服 | 退回乐咕乐股（有 PE/PB 无分位），或让用户从行情软件手抄；**任何情况下不许编数** |
| 乐咕无历史分位字段 | 只能拿到绝对值 | 用蛋卷分位；都没有就改问"是否持有"，用 `position --series` 自带历史算 |
| 快照是单点的 | `07` 里的表只代表 2026-10-16 | 超过 6 个月或 10Y 国债偏离 >50bp，必须重取 |
| 费率/税率会变 | 分红税、佣金、印花税 | 以当期券商与基金合同为准，脚本参数可覆盖 |
| 分级基金已退场 | 2020 年底前全部清理（书里 2017 年还在讲） | 不要再推荐分级 A/B；`06-qa` 已标注 |

## 回答纪律

- **先分类再判断**：任何"能不能买"的问题，先说清品种类型、该用哪个方法、用哪套阈值，再给数字。
- **口径必须交代**：说"低估/高估"时，同时说明是 PE 绝对值、历史分位，还是盈利收益率，以及用的是 book 还是 cal。三者在 2026 年经常互相打架（中证红利就是典型：盈利收益率说买，分位说贵）。
- **不替用户下注**：给区间和规则，不承诺收益；明确"低估是一个区域，不是一个点"。
- **不虚构实时估值**：书里的数字是 2017 年的标本，快照是 2026-10-16 的。用户问"现在"，必须让用户提供当期数据或说明需联网查询。
- **交代数据三要素**：回答里出现任何 PE/PB/分位/股息率时，同时给出**数值、来源（蛋卷/乐咕/中证官网/用户自报/rawdata 自算）、时间（发帖）**。三者缺一，就标注"未经核实"。不同源同一指数能差 20%+（恒生 10.70 vs 13.79），只说数字等于骗人。
- **能自己算就别只报结论**：PE 是"总市值 ÷ 净利润"，PB 是"总市值 ÷ 净资产"。凡是给出 PE/PB，优先用 `rawdata.py` 算一遍，把分子分母与逐只误差一起说；用户问"这数据真的假的"，就给他 `--csv` 明细让他自己用计算器抽查一只。
- **自定规则要声明**：分位 30%/70% 分界线是本工具自定的，书里没有；校准变体 A/B 是判断题不是定论。这类"我补的"必须和"书里写的"分开说。
- **阈值会过期**：距 2026-10-16 超过一年，或 10Y 国债偏离 1.65% 超 50bp、货基回到 2.5% 以上时，先重跑 `calibrate` 再回答。
- **风险前置**：指数基金是长期资产，1 年内要用的钱不该投；股票资产占家庭流动资产比例不宜低于 30%（低于 30% 对总收益提升不明显）。
- **先过禁止清单**：任何方案在给出去之前，对照 `references/06-qa.md` 第十节那 12 条硬约束（不借钱/不加杠杆/不碰分级B/不一次全投/不投长期亏损行业/不重仓单一行业/不买规模过小的/不预测点数/不追高……）。命中任一条，先纠正再回答。
- 这是投资方法论工具，不是投资建议；涉及具体金额与决策时提示用户自行判断并承担风险。
